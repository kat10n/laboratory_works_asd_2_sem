# Лабораторная работа 6. Bash-скрипт очистки устаревших файлов

## Описание

Скрипт на Bash для поиска и удаления файлов с заданным суффиксом, к которым не обращались более указанного числа дней. Перед удалением показывает список найденных файлов и запрашивает подтверждение.

## Использование

```bash
bash cleanup.sh <суффикс> <дней>
```

Примеры:

```bash
# найти и удалить .log файлы, к которым не обращались более 30 дней
bash cleanup.sh .log 30

# то же самое для .tmp файлов, порог 7 дней
bash cleanup.sh .tmp 7
```

## Как работает

1. Проверяет что переданы ровно два аргумента, иначе выводит подсказку и завершается.
2. Проверяет что второй аргумент - целое число (защита от случайного ввода).
3. Выполняет `find . -name "*<суффикс>" -atime +<дней> -type f` - ищет файлы рекурсивно от текущей директории.
4. Если файлов нет - сообщает об этом и завершается.
5. Выводит список найденных файлов и запрашивает подтверждение (y/n).
6. При подтверждении удаляет каждый файл и считает количество удалённых.

## Параметры find

- `-name "*<суффикс>"` - фильтр по окончанию имени файла
- `-atime +N` - файлы, время последнего обращения (access time) которых старше N дней
- `-type f` - только обычные файлы, директории не затрагиваются

## Пример вывода

```
Ищем файлы *.log, к которым не обращались более 30 дней...

Найдены следующие файлы:
./logs/app_2024.log
./logs/debug_old.log

Удалить все эти файлы? (y/n): y
Удалён: ./logs/app_2024.log
Удалён: ./logs/debug_old.log

Готово. Удалено файлов: 2
```

## Примечания

Скрипт работает от текущей директории, из которой запущен. Перед запуском убедитесь, что находитесь в нужной папке. Удаление необратимо - файлы не перемещаются в корзину.
